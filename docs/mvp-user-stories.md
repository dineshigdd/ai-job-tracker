# User Stories
---
## User Roles
- Job Seeker

## Draft User Stories
| ID | As a... | I want to... | So that... |
| :--- | :--- | :--- | :--- |
| **US-01** | Job Seeker | Register an account and log in securely | My job data remains private and accessible across sessions. |
| **US-02** | Job Seeker | Add, edit, and delete job applications (Company, Role, Status, URL) | I can keep my pipeline accurate and up to date. |
| **US-03** | Job Seeker | Update the application status (Applied, Interviewing, Offer, Rejected) | I can visualize where I stand in my hiring processes. |
| **US-04** | Job Seeker | Upload my resume as a PDF | The system can parse and evaluate my core qualifications. |
| **US-05** | Job Seeker | Receive AI-driven feedback on my resume | I can tailor and improve it for specific job descriptions. |
| **US-06** | Job Seeker | Generate an AI-powered cover letter based on a job description | I can save time applying to positions. |
| **US-07** | Job Seeker | View a dashboard with application statistics | I can track my overall job hunt performance at a glance. |
| **US-08** | Job Seeker | Search and filter my applications by keyword or status | I can quickly find specific entries without scrolling endlessly. |
